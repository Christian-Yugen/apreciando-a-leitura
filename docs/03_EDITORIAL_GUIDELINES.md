# APRECIANDO A LEITURA
# Editorial Guidelines
Versão 1.0

---

# 1. Objetivo

Este documento define os padrões para produção do conteúdo editorial do
Apreciando a Leitura.

Todo conteúdo publicado deve seguir estas diretrizes.

---

# 2. Tipos de Conteúdo

O projeto possui os seguintes tipos de conteúdo.

- Resenha
- Livro
- Autor
- Coleção
- Série
- Editora
- Gênero
- Timeline
- Página institucional

---

# 3. Fluxo Editorial

Todo conteúdo segue obrigatoriamente este fluxo.

Pesquisa

↓

Leitura

↓

Produção

↓

Revisão

↓

Publicação

↓

Relacionamentos

↓

Atualização futura

Nenhum conteúdo é publicado diretamente.

---

# 4. Estrutura de uma Resenha

Toda resenha deve possuir.

- Introdução
- Contexto da obra
- Análise
- Pontos positivos
- Limitações
- Conclusão
- Livros relacionados

---

# 5. Estrutura da Página de Livro

Toda página de livro deve conter.

- Capa
- Título
- Autor
- Editora
- Ano
- ISBN
- Sinopse
- Dados técnicos
- Resenhas relacionadas
- Livros relacionados

---

# 6. Estrutura da Página de Autor

Toda página de autor deve conter.

- Nome
- Fotografia
- Biografia
- Nacionalidade
- Obras
- Coleções
- Autores relacionados

---

# 7. Estrutura da Página de Coleção

Toda coleção deve possuir.

- Nome
- Introdução
- Objetivo
- Livros
- Autores
- Resenhas

---

# 8. Estrutura da Página de Série

Toda série deve possuir.

- Nome
- Ordem de leitura
- Livros
- Resenhas

---

# 9. Estrutura da Página de Editora

Toda editora deve conter.

- Nome
- História
- País
- Livros publicados

---

# 10. Critérios para Publicação

Antes da publicação verificar.

✓ Ortografia

✓ Gramática

✓ Metadados

✓ Links internos

✓ Imagens

✓ Dados do livro

✓ SEO

✓ Conteúdo relacionado

---

# 11. Imagens

Todas as capas devem.

- possuir boa resolução
- manter proporção original
- não receber filtros
- não conter marca d'água

---

# 12. Citações

Toda citação deve.

- informar a fonte
- preservar o texto original
- utilizar destaque visual

---

# 13. Links Internos

Sempre relacionar.

Livro → Autor

Livro → Coleção

Livro → Série

Livro → Editora

Livro → Resenha

Autor → Livros

Coleção → Livros

Nunca publicar páginas isoladas.

---

# 14. Atualização

Sempre que novas informações surgirem.

Atualizar.

Nunca criar páginas duplicadas.

---

# 15. Checklist Final

Antes de publicar confirmar.

✓ Estrutura correta

✓ Dados completos

✓ Links funcionando

✓ Conteúdo relacionado

✓ Imagens corretas

✓ SEO preenchido

✓ Revisão concluída
