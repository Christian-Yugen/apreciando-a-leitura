# APRECIANDO A LEITURA
# Changelog

Todas as alterações relevantes do projeto serão registradas neste documento.

Este arquivo segue o princípio de versionamento contínuo, permitindo acompanhar a evolução do sistema ao longo do tempo.

---

# Versionamento

O projeto utiliza versionamento semântico.

Formato.

MAJOR.MINOR.PATCH

Onde.

MAJOR

Mudanças incompatíveis.

MINOR

Novas funcionalidades compatíveis.

PATCH

Correções e pequenos ajustes.

---

# Tipos de Alteração

As alterações devem ser registradas utilizando as seguintes categorias.

Added

Novas funcionalidades.

Changed

Alterações em funcionalidades existentes.

Deprecated

Funcionalidades que deixarão de ser utilizadas.

Removed

Funcionalidades removidas.

Fixed

Correções de erros.

Security

Correções relacionadas à segurança.
