# APRECIANDO A LEITURA
# SEO Guide
Versão 1.0

---

# 1. Objetivo

Este documento define as diretrizes de SEO do projeto
Apreciando a Leitura.

Todo conteúdo publicado deve seguir estas recomendações.

---

# 2. Princípios

Todo conteúdo deve ser.

- Encontrável
- Indexável
- Relevante
- Organizado
- Atualizado

---

# 3. URLs

Toda página pública deve possuir.

- URL amigável
- slug único
- estrutura simples
- estabilidade após publicação

Evitar.

- parâmetros desnecessários
- URLs longas
- caracteres especiais

---

# 4. Títulos

Toda página deve possuir apenas um H1.

O H1 deve representar claramente o assunto da página.

Evitar títulos genéricos.

---

# 5. Meta Title

Toda página deve possuir.

- título único
- descrição objetiva
- relação direta com o conteúdo

---

# 6. Meta Description

Toda página deve possuir uma descrição resumindo o conteúdo.

Evitar descrições duplicadas.

---

# 7. Hierarquia de Conteúdo

Utilizar corretamente.

H1

↓

H2

↓

H3

↓

H4

Nunca utilizar títulos apenas para alterar aparência.

---

# 8. Conteúdo

Todo conteúdo deve ser.

- original
- relevante
- atualizado
- organizado

Evitar duplicação.

---

# 9. Links Internos

Sempre relacionar conteúdos.

Livro → Autor

Livro → Resenha

Livro → Coleção

Livro → Série

Autor → Livros

Coleção → Livros

Nunca publicar páginas isoladas.

---

# 10. Links Externos

Utilizar apenas quando agregarem valor.

Verificar periodicamente se continuam funcionando.

---

# 11. Imagens

Toda imagem deve possuir.

- texto alternativo
- nome de arquivo descritivo
- tamanho otimizado

---

# 12. Estrutura das Páginas

Toda página deve possuir.

- título
- conteúdo principal
- conteúdo relacionado
- navegação

---

# 13. Dados Estruturados

Sempre que possível utilizar dados estruturados para facilitar a indexação.

Exemplos.

- Livro
- Autor
- Resenha
- Organização
- Breadcrumb

---

# 14. Sitemap

Toda página pública deve ser incluída no sitemap.

Remover páginas despublicadas.

---

# 15. Robots

Permitir indexação apenas das páginas públicas.

Bloquear páginas administrativas.

---

# 16. Canonical

Toda página deve possuir URL canônica quando necessário.

Evitar conteúdo duplicado.

---

# 17. Atualização de Conteúdo

Sempre que uma página receber alterações relevantes.

Atualizar.

- conteúdo
- metadados
- data de atualização

---

# 18. Monitoramento

Acompanhar periodicamente.

- páginas indexadas
- erros de rastreamento
- links quebrados
- desempenho nas buscas

---

# 19. Conteúdo Permanente

Priorizar conteúdos que permaneçam úteis ao longo do tempo.

Atualizar quando necessário.

Evitar criar múltiplas páginas para o mesmo assunto.

---

# 20. Checklist

Antes da publicação verificar.

✓ URL amigável

✓ Slug único

✓ Meta Title

✓ Meta Description

✓ Hierarquia de títulos

✓ Links internos

✓ Texto alternativo nas imagens

✓ Conteúdo relacionado

✓ Sitemap atualizado

✓ Página pronta para indexação
