# APRECIANDO A LEITURA
# Accessibility
Versão 1.0

---

# 1. Objetivo

Este documento define os requisitos mínimos de acessibilidade do projeto
Apreciando a Leitura.

Toda funcionalidade desenvolvida deve seguir estas diretrizes.

---

# 2. Princípios

O sistema deve ser.

- Perceptível
- Operável
- Compreensível
- Robusto

Sempre priorizando a experiência de todos os usuários.

---

# 3. Navegação por Teclado

Todo o sistema deve ser utilizável sem mouse.

Todos os elementos interativos devem receber foco.

A ordem de navegação deve seguir a estrutura visual da página.

Nunca criar elementos inacessíveis ao teclado.

---

# 4. Indicador de Foco

Todo elemento focável deve apresentar indicação visual clara.

Nunca remover o outline padrão sem substituição equivalente.

---

# 5. Links

Todo link deve possuir texto descritivo.

Evitar.

- Clique aqui
- Saiba mais
- Ler mais

Preferir.

- Ler resenha de Dom Casmurro
- Conhecer Machado de Assis

---

# 6. Botões

Todo botão deve possuir.

- texto claro
- função objetiva
- estado de foco
- estado desabilitado quando necessário

Nunca utilizar apenas ícones sem descrição acessível.

---

# 7. Imagens

Toda imagem informativa deve possuir texto alternativo.

Exemplos.

Capa do livro.

Fotografia do autor.

Ilustração de coleção.

Imagens decorativas devem utilizar alt vazio.

---

# 8. Contraste

Todo texto deve possuir contraste suficiente com o fundo.

Nunca utilizar combinações que dificultem a leitura.

---

# 9. Tipografia

Utilizar fontes legíveis.

Evitar.

- textos muito pequenos
- blocos extensos sem espaçamento
- alinhamento que prejudique a leitura

---

# 10. Formulários

Todo campo deve possuir.

- label
- identificação clara
- mensagem de erro
- ajuda quando necessária

Nunca utilizar placeholder como único identificador.

---

# 11. Mensagens de Erro

Toda mensagem deve informar.

- o problema
- onde ocorreu
- como corrigir

Evitar mensagens genéricas.

---

# 12. Tabelas

Utilizar tabelas apenas para dados.

Sempre utilizar.

- cabeçalhos
- estrutura correta
- leitura lógica

---

# 13. Estrutura de Títulos

Toda página deve possuir apenas um H1.

Os demais títulos devem seguir a hierarquia.

H2

H3

H4

Nunca utilizar títulos apenas para alterar aparência.

---

# 14. Listas

Utilizar listas quando houver sequência de itens.

Evitar criar listas utilizando apenas parágrafos.

---

# 15. Links Externos

Sempre indicar quando um link abrir outra página.

Quando possível, informar ao usuário que o destino é externo.

---

# 16. Conteúdo Multimídia

Vídeos devem possuir legendas quando disponíveis.

Áudios devem possuir transcrição quando aplicável.

---

# 17. Responsividade

Todo conteúdo deve permanecer acessível.

Desktop

Tablet

Mobile

Sem perda de funcionalidade.

---

# 18. Linguagem

Utilizar linguagem clara.

Evitar.

- siglas sem explicação
- frases excessivamente longas
- ambiguidades

---

# 19. Componentes

Todo componente reutilizável deve possuir.

- navegação por teclado
- foco visível
- suporte a leitores de tela
- estrutura semântica

---

# 20. Checklist

Antes da publicação verificar.

✓ Navegação por teclado

✓ Foco visível

✓ Texto alternativo nas imagens

✓ Hierarquia correta de títulos

✓ Labels em formulários

✓ Contraste adequado

✓ Estrutura semântica

✓ Compatibilidade com leitores de tela

✓ Responsividade
