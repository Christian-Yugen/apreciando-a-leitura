Este documento descreve o planejamento evolutivo do projeto

incrementais.

# 9. Critérios para Novas Funcionalidades

Toda nova funcionalidade deve responder.

- Resolve um problema real?
- Está alinhada com o propósito do projeto?
- Melhora a experiência do leitor?
- Mantém a simplicidade do sistema?
- Justifica o esforço de desenvolvimento?

Caso contrário.

Deve permanecer fora do roadmap.
